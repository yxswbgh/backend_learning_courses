01 命令行

ps aux

02 Git 最低闭环

git clone <url>

git init
git add .
git commit -m "init"
git branch -M main
git remote add origin <url>
git push -u origin main

git switch -c feature/x
git add .
git commit -m "feat: x"
git switch main
git merge feature/x
git push

冲突：改到最终内容，删标记，git add .，git commit，git push。

05 curl

curl -X POST "http://localhost:8080/api/users" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"name":"Ada"}'

看清方法、URL、Header、Body、Token 五件事。

06 Network

  • URL：请求了哪个接口。
  • Method：GET / POST / PUT / DELETE。
  • Status：2xx / 4xx / 5xx。
  • Time：总耗时。
  • Headers、Payload、Response：带什么、发什么、回什么。

07 Docker MySQL

docker run -d \
  --name mysql-stage0 \
  -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=stage0 \
  -v mysql_stage0:/var/lib/mysql \
  mysql:8.4

docker exec -it mysql-stage0 mysql -uroot -pstage0

CREATE DATABASE stage0;
USE stage0;
CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(50) NOT NULL
);

-p 宿主端口:容器端口。失败先看 docker logs。

三条过关线

  • Git 本地提交能推到远程，冲突能收口。
  • Docker 能起 MySQL，连上后建库建表。
  • Network 中能读懂一条请求。
